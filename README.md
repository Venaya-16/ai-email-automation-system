# 📧 AI Email Automation System

An AI-powered email assistant built using **Google Gemini** that helps users generate professional emails, automate replies, rewrite drafts, and adjust email tone with a simple interactive interface.

---

## 📖 Project Overview

Writing professional emails can be time-consuming, especially when different situations require different communication styles. Whether it's applying for a job, responding to a customer, or sending a sales proposal, maintaining the right tone and structure is important.

This project leverages Google's Gemini model to simplify business communication by generating context-aware, professional emails while also providing tools to reply, rewrite, and personalize existing messages.

---

## 🚀 Features

- ✉️ Generate professional emails for HR, Sales, Support, and General communication
- 💬 Automatically generate context-aware email replies
- 📝 Rewrite existing emails to improve grammar, clarity, and professionalism
- 🎭 Change the tone of emails while preserving the original meaning
- 🤖 Powered by Google Gemini
- 🖥 Interactive Gradio interface

---

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ai-email-automation-system.git
```

Move into the project folder

```bash
cd ai-email-automation-system
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a Google Colab Secret

```
GEMINI_API_KEY
```

Run all notebook cells.
